# 集合：

## 常见的集合类型
```

Set<String>，像存储学生姓名，一个 Set 里存 “张三”“李四” 等；
List<Long>，如记录一系列订单号（假设订单号用长整型），像[123456789 L, 987654321 L]；
List<UserDTO>，把每个用户的信息封装成 UserDTO 对象，再放到 List 里，如一个 List 存多个 UserDTO，每个 UserDTO 含用户 id、姓名等信息。

```
## 代码实例
```java
// 创建学生姓名集合
Set<String> studentNames = new HashSet<>();
// 添加元素
studentNames.add("张三");
studentNames.add("李四");
studentNames.add("王五");
studentNames.add("张三"); // 重复元素自动忽略

// 验证唯一性
System.out.println(studentNames.size()); // 输出 3（"张三"只保留一个）

// 遍历（无序输出）
for (String name : studentNames) {
    System.out.println(name);
}
// 可能输出：李四、王五、张三

// 保留插入顺序的实现
Set<String> orderedNames = new LinkedHashSet<>();
orderedNames.add("张三");
orderedNames.add("李四");
// 遍历时会按添加顺序输出
```

```java
// 创建订单号列表
List<Long> orderIds = new ArrayList<>();

// 列表变为 [123456789, 555666777, 987654321, 111222333]

// 转换为数组
Long[] idArray = orderIds.toArray(new Long[0]);

// 流式处理（Java 8+）
List<Long> filtered = orderIds.stream()
    .filter(id -> id > 500000000L)
    .collect(Collectors.toList());
```


```java
// UserDTO 定义
@Data // Lombok 注解自动生成 getter/setter
public class UserDTO {
    private Long id;
    private String name;
    private Integer age;
}

// 创建用户列表
List<UserDTO> userList = new ArrayList<>();
userList.add(new UserDTO(1L, "张三", 20));
userList.add(new UserDTO(2L, "李四", 22));

// 遍历并处理
for (UserDTO user : userList) {
    System.out.println(user.getName() + " (ID: " + user.getId() + ")");
}

// Stream API 高级操作
// 1. 按年龄过滤
List<UserDTO> adults = userList.stream()
    .filter(u -> u.getAge() >= 18)
    .collect(Collectors.toList());

// 2. 转换为 ID 列表
List<Long> userIds = userList.stream()
    .map(UserDTO::getId)
    .collect(Collectors.toList());

// 3. 查找特定用户
Optional<UserDTO> target = userList.stream()
    .filter(u -> "张三".equals(u.getName()))
    .findFirst();
```


# 数组

| 问题场景           | 数组的缺陷           | 集合的解决方案                        |
| -------------- | --------------- | ------------------------------ |
| **动态增删元素**     | 需手动扩容/移动数据，代码冗余 | 自动扩容，`add()` / `remove()` 直接操作 |
| **唯一性校验（如姓名）** | 需 O (n) 循环检查重复  | `Set` 通过哈希表 **O (1) 完成去重**     |
| **结构化对象操作**    | 无内置方法，需硬编码遍历逻辑  | 支持 Stream API 实现 **声明式操作**     |
尽管集合优势明显，但以下场景数组更合适：
1. **性能敏感的底层计算**：  
    大规模科学计算中，连续内存的数组能更好利用 CPU 缓存（如矩阵运算）。
2. **固定长度的简单数据**：  
    已知精确数量的配置项（如一周 7 天的枚举值）。
3. **JNI/跨语言交互**：
