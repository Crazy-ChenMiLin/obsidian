# What 
- `List<MV_CC_DEVICE_INFO>` 是**类型安全的泛型集合**，仅能存放 `MV_CC_DEVICE_INFO` 类型的对象；
- `MV_CC_DEVICE_INFO` 是封装**设备（多为工业相机）信息**的实体类，通常来自相机厂商的 SDK；

``` java
// 模拟 MV_CC_DEVICE_INFO 类的核心结构（实际是 SDK 提供的类）
public class MV_CC_DEVICE_INFO {
    // 设备序列号
    private String strSerialNumber;
    // 设备IP地址
    private String strIpAddress;
    // 设备型号
    private String strModelName;

    // 标准的 getter/setter 方法
    public String getStrSerialNumber() {
        return strSerialNumber;
    }

    public void setStrSerialNumber(String strSerialNumber) {
        this.strSerialNumber = strSerialNumber;
    }

    // 其他字段的 getter/setter 省略...
}
```

#### 2. 实际使用示例

`List<MV_CC_DEVICE_INFO>` 最常见的场景是 **批量存储扫描到的多个设备信息**，比如遍历局域网内所有可用的工业相机，把每个相机的信息封装成 `MV_CC_DEVICE_INFO` 对象，再存入 List：

``` java
import java.util.ArrayList;
import java.util.List;

public class DeviceManager {
    public static void main(String[] args) {
        // 1. 创建只能存放 MV_CC_DEVICE_INFO 的 List 集合
        List<MV_CC_DEVICE_INFO> deviceList = new ArrayList<>();

        // 2. 模拟扫描到第一个相机设备
        MV_CC_DEVICE_INFO camera1 = new MV_CC_DEVICE_INFO();
        camera1.setStrSerialNumber("MV12345678");
        camera1.setStrIpAddress("192.168.1.100");
        camera1.setStrModelName("MV-CE200-10GM");
        deviceList.add(camera1); // 存入集合

        // 3. 模拟扫描到第二个相机设备
        MV_CC_DEVICE_INFO camera2 = new MV_CC_DEVICE_INFO();
        camera2.setStrSerialNumber("MV87654321");
        camera2.setStrIpAddress("192.168.1.101");
        camera2.setStrModelName("MV-CE120-10GC");
        deviceList.add(camera2); // 存入集合

        // 4. 遍历集合，处理所有设备信息
        for (MV_CC_DEVICE_INFO device : deviceList) {
            System.out.println("设备序列号：" + device.getStrSerialNumber());
            System.out.println("设备IP：" + device.getStrIpAddress());
            System.out.println("----------");
        }
    }
}
```

**输出结果**：

```
设备序列号：MV12345678
设备IP：192.168.1.100
----------
设备序列号：MV87654321
设备IP：192.168.1.101
----------
```




  # *是否需要定界？** 
 不需要。大多数泛型（如`ArrayList<T>`、`Box<T>`）都不带定界，默认适配所有引用类型。
- **怎么知道泛型能通用什么类型？** #flashcard
    - 若未指定定界：通用所有引用类型（`String`、`Integer`、自定义类等，基本类型需用包装类）。
    - 若指定了上界（`T extends A`）：只能是`A`或`A`的子类 / 实现类。
    - 若指定了下界（`<? super A>`）：只能是`A`或`A`的父类。
- **判断是否需要定界的简单原则**：看你的代码中是否用到了泛型类型的**特定方法 / 特性**。用到了就加对应定界，没用到就不用加。
