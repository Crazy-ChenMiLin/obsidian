调试并发问题：

- 使用日志（带线程名/ID、上下文），保证可重放或可过滤的日志。
- 使用 jstack 生成线程转储，分析死锁或阻塞位置。
- 使用 profiler（Java Flight Recorder、async-profiler）进行热点分析。

性能优化建议：

- 缩小锁粒度，减少锁持有时间；避免在锁内做 I/O 或长时间计算。
- 优先使用无锁数据结构（ConcurrentHashMap、LongAdder、AtomicLong）。
- 对热点计数使用 LongAdder 替代 AtomicLong 以降低争用。

处理中断：

- 捕获 InterruptedException 后，应合理处理或恢复中断状态：

```java
Thread.currentThread().interrupt(); // 恢复中断
```

常见误区与建议：

- 不要滥用 synchronized，考虑更细粒度的锁或无锁方案。
- 在生产环境中定期生成线程转储以便事后分析非确定性问题。
