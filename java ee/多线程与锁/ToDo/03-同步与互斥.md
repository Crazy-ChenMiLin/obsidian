概述：互斥是并发编程的基础，常用机制包括 synchronized、Lock、volatile 与原子类（Atomic）。本文件给出示例与对比，强调正确使用模式。

关键点：

- synchronized：基于对象监视器，支持可重入（同一线程可多次获取锁），语法糖支持方法级与代码块级锁定。
- ReentrantLock：显示锁，支持公平锁、中断获取、尝试获取（tryLock）、Condition（替代 wait/notify）。
- volatile：保证可见性和禁止指令重排，但不保证原子性（如 i++ 仍需同步或原子类型）。
- Atomic 类：提供无锁原子操作（AtomicInteger、AtomicReference 等），适合高并发计数或原子更新场景。

示例：synchronized

```java
public class Counter {
    private int count = 0;

    public synchronized void increment() {
        count++;
    }

    public synchronized int get() {
        return count;
    }
}
```

示例：ReentrantLock

```java
import java.util.concurrent.locks.ReentrantLock;

public class CounterLock {
    private final ReentrantLock lock = new ReentrantLock();
    private int count = 0;

    public void increment() {
        lock.lock();
        try {
            count++;
        } finally {
            lock.unlock();
        }
    }
}
```

可重入性说明：

```java
public class ReentrantExample {
    public synchronized void outer() {
        inner(); // 同一线程可以再次获得同一个锁
    }

    public synchronized void inner() {
        // ...
    }
}
```

实战建议：

- 优先考虑无锁或低争用的数据结构（ConcurrentHashMap、LongAdder）。
- 缩小锁粒度并避免在锁内执行长耗时或阻塞操作。
- 在可能的地方使用 tryLock 和超时，以避免死等。
