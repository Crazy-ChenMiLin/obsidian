常见实现方式：

1. 继承 Thread
2. 实现 Runnable
3. 实现 Callable<V> 并结合 Future
4. 使用 ExecutorService 提交任务（线程池）
5. CompletableFuture（异步组合与链式调用）
6. ForkJoinPool / RecursiveTask（分治并行）
7. parallelStream（简化并行数据处理）

示例：Callable + Future

```java
ExecutorService es = Executors.newFixedThreadPool(4);
Future<Integer> f = es.submit(() -> {
    Thread.sleep(1000);
    return 42;
});
int result = f.get();
es.shutdown();
```

示例：CompletableFuture

```java
CompletableFuture.supplyAsync(() -> expensive())
    .thenApplyAsync(x -> transform(x))
    .exceptionally(e -> fallback());
```

选择建议：

- 需要任务管理和线程复用：使用 ExecutorService。
- 需要链式/回调式异步：使用 CompletableFuture（注意异常传播和线程上下文）。
- 并行分治任务：使用 ForkJoinPool（或 parallelStream），并监控并行度与任务粒度以避免过度线程切换。
