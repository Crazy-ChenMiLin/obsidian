概述：进程和线程的本质区别、对比与使用场景。此文档只包含核心概念、对比表述与实践建议，详细示例见其他章节或 [[09-附录-代码片段与示例]]。

要点：

- 进程（Process）：操作系统分配资源的基本单位，拥有独立的地址空间、文件描述符表等。
- 线程（Thread）：CPU 调度的基本单位，属于进程并共享进程内存与资源。

对比要点：

- 隔离性：进程相互隔离；线程共享内存，易于通信但需要同步。
- 开销：创建/切换进程开销大于线程。
- 通信：进程间通信（IPC：管道、Socket、共享内存），线程间通过共享内存（变量）沟通需要同步。

使用场景建议：

- 单 JVM 内部并发：使用线程（或线程池）处理并发任务。
- 需要隔离或独立部署：使用进程（多个 JVM 实例或微服务）。

注意事项与常见误区：

- 误以为线程天然并行：线程可能因 CPU 核数、锁竞争或 I/O 等原因表现为串行或阻塞。
- 误用共享可变状态：尽量用不可变对象或适当的同步策略。
