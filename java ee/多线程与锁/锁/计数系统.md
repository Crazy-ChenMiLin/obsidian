线程安全的计数器示例
# ReentrantLock 锁 count
```java
import java.util.concurrent.locks.ReentrantLock;

public class ThreadSafeCounter {
    private final ReentrantLock lock = new ReentrantLock();
    private int count = 0;
    
    public void increment() {
        lock.lock();
        try {
            count++;
        } finally {
            lock.unlock();
        }
    }
    
    public int getCount() {
        lock.lock();
        try {
            return count;
        } finally {
            lock.unlock();
        }
    }
}
```

# synchronized 锁count

```java
Public class ThreadSafeCounter {
    Private int count = 0;
    //  synchronized 修饰实例方法 = 自动加锁/解锁
    public synchronized void increment() {
        count++;
    }
    
    public synchronized int getCount() {
        return count;
    }
}

```
