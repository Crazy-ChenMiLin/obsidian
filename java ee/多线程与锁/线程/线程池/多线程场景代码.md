# 场景 1：简单批量任务 callable+线程池+限时 Future

```JAVA
public String callableWithPool() { 
    // 1. 定义Callable任务（你说的"电商"，带返回值）
    Callable<String> task = () -> {
        System.out.println("Callable执行");
        TimeUnit.SECONDS.sleep(1);
        return "Callable执行结果";
    };

    // 2. 提交到线程池，返回Future
    Future<String> future = asyncPool.submit(task);

    // 3. 生产必须：限时获取，防止永久阻塞
    try {
        return future.get(2, TimeUnit.SECONDS);
    } catch (TimeoutException e) {
        future.cancel(true); // 超时取消任务
        return "执行超时";
    } catch (Exception e) {
        return "执行异常";
    }
}
```

# 场景三：链式调用
`supplyAsync` = 语法糖 = **自动封装 Callable 的快捷方式**

``` java
CompletableFuture.supplyAsync(() -> "商品ID:1001，商品名：手机", asyncPool)
    .thenApply(goods -> goods + " → 库存：20台")
    .thenApply(stock -> stock + " → 单价：3999元，总价：79980元") // 加一步计算
    .thenAccept(finalInfo -> System.out.println(finalInfo))
    .exceptionally(e -> {
        System.out.println("失败：" + e.getMessage());
        return null;
    });
```
