# `.sync()` 和 `CompletableFuture` 的关系
- **Java 原生 `CompletableFuture` 没有 `.sync()` 方法**！
- `.sync()` 是 **第三方异步框架**（Netty、Vert. X、RxJava 等）的方法，作用是：**阻塞当前线程，等待异步任务执行完成**（异步转同步）；
- `CompletableFuture` 中**和 `.sync()` 功能完全一致**的原生方法是：**`.join()` / `.get()`**；
- 两者关系：**互补工具** —— `CompletableFuture` 负责**异步任务编排**，`.sync()`（或原生 join/get）负责**强制同步等待异步结果**。
	```java
	import java.util.concurrent.CompletableFuture;
 
 public class Test {
     public static void main(String[] args) {
         // 1. 异步执行任务（CompletableFuture 核心：异步）
         CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
             try { Thread.sleep(1000); } catch (InterruptedException e) {}
             return "异步任务结果";
         });
 
         // 2. 【同步等待】等价于 .sync()：阻塞主线程，直到任务完成
         String result = future.join(); 
         // String result = future.get(); // 需处理异常
 
         System.out.println(result); // 输出：异步任务结果
     }
 }
 
	```
