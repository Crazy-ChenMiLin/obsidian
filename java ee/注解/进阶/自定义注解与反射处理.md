# 自定义注解与反射处理

## 1. 反射概述

### 1.1 什么是反射？

反射是 Java 的动态特性，它允许程序在运行时获取类的信息（属性、方法、构造器等），并可以动态调用对象的方法或修改字段值。

### 1.2 反射的核心类

- `Class`：表示类或接口
- `Field`：表示类的属性
- `Method`：表示类的方法
- `Constructor`：表示类的构造器
- `Annotation`：表示注解

## 2. 获取 Class 对象

### 2.1 三种方式

```java
// 方式一：通过类名.class
Class<?> clazz1 = String.class;

// 方式二：通过对象的 getClass() 方法
String str = "hello";
Class<?> clazz2 = str.getClass();

// 方式三：通过 Class.forName() 方法
Class<?> clazz3 = Class.forName("java.lang.String");
```

## 3. 获取注解信息

### 3.1 判断是否存在注解

```java
Class<?> clazz = MyClass.class;

// 判断类上是否存在某个注解
boolean hasAnnotation = clazz.isAnnotationPresent(MyAnnotation.class);
```

### 3.2 获取类上的注解

```java
// 获取指定注解（只能获取 RUNTIME 保留策略的注解）
MyAnnotation annotation = clazz.getAnnotation(MyAnnotation.class);

if (annotation != null) {
    String name = annotation.name();
    int age = annotation.age();
    System.out.println("name: " + name + ", age: " + age);
}
```

### 3.3 获取所有注解

```java
// 获取所有注解
Annotation[] annotations = clazz.getAnnotations();

for (Annotation annotation : annotations) {
    System.out.println(annotation.annotationType().getSimpleName());
}
```

## 4. 获取方法上的注解

```java
Class<?> clazz = MyClass.class;
Method[] methods = clazz.getDeclaredMethods();

for (Method method : methods) {
    // 判断方法上是否存在某个注解
    if (method.isAnnotationPresent(MyAnnotation.class)) {
        MyAnnotation annotation = method.getAnnotation(MyAnnotation.class);
        System.out.println("方法: " + method.getName() + ", 注解信息: " + annotation.name());
    }
}
```

## 5. 获取字段上的注解

```java
Class<?> clazz = MyClass.class;
Field[] fields = clazz.getDeclaredFields();

for (Field field : fields) {
    if (field.isAnnotationPresent(MyAnnotation.class)) {
        MyAnnotation annotation = field.getAnnotation(MyAnnotation.class);
        System.out.println("字段: " + field.getName() + ", 注解信息: " + annotation.name());
    }
}
```

## 6. 自定义注解实战

### 6.1 定义注解

```java
import java.lang.annotation.*;

@Retention(RetentionPolicy.RUNTIME)
@Target({ElementType.TYPE, ElementType.METHOD, ElementType.FIELD})
public @interface TableField {
    String columnName() default "";
    String type() default "";
    int length() default 0;
}
```

### 6.2 使用注解

```java
@TableField(columnName = "user_name", type = "varchar", length = 50)
public class User {
    
    @TableField(columnName = "id", type = "bigint", length = 20)
    private Long id;
    
    @TableField(columnName = "user_name", type = "varchar", length = 50)
    private String userName;
    
    @TableField(columnName = "age", type = "int", length = 3)
    private Integer age;
}
```

### 6.3 通过反射处理注解

```java
import java.lang.reflect.Field;

public class AnnotationProcessor {
    
    public static String generateSQL(Class<?> clazz) {
        StringBuilder sql = new StringBuilder();
        
        // 获取表名（类上的注解）
        if (clazz.isAnnotationPresent(TableField.class)) {
            TableField classAnnotation = clazz.getAnnotation(TableField.class);
            String tableName = clazz.getSimpleName().toLowerCase();
            sql.append("CREATE TABLE ").append(tableName).append(" (");
        }
        
        // 获取字段信息（字段上的注解）
        Field[] fields = clazz.getDeclaredFields();
        for (int i = 0; i < fields.length; i++) {
            Field field = fields[i];
            
            if (field.isAnnotationPresent(TableField.class)) {
                TableField annotation = field.getAnnotation(TableField.class);
                
                String columnName = annotation.columnName();
                String type = annotation.type();
                int length = annotation.length();
                
                sql.append(columnName).append(" ").append(type);
                if (length > 0) {
                    sql.append("(").append(length).append(")");
                }
                
                if (i < fields.length - 1) {
                    sql.append(", ");
                }
            }
        }
        
        sql.append(");");
        return sql.toString();
    }
    
    public static void main(String[] args) {
        String sql = generateSQL(User.class);
        System.out.println(sql);
        // 输出: CREATE TABLE user (id bigint(20), user_name varchar(50), age int(3));
    }
}
```

## 7. 注解处理器实现

### 7.1 定义注解

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface Validate {
    String pattern() default "";
    int min() default 0;
    int max() default Integer.MAX_VALUE;
    boolean required() default true;
}
```

### 7.2 使用注解

```java
public class UserService {
    
    @Validate(pattern = "^[a-zA-Z0-9_]+$", min = 3, max = 20)
    public void createUser(String username, String password) {
        System.out.println("创建用户: " + username);
    }
}
```

### 7.3 实现校验逻辑

```java
import java.lang.reflect.Method;
import java.util.regex.Pattern;

public class ValidationProcessor {
    
    public static void validate(Object target, Method method, Object... args) throws Exception {
        if (!method.isAnnotationPresent(Validate.class)) {
            return;
        }
        
        Validate validation = method.getAnnotation(Validate.class);
        String pattern = validation.pattern();
        int min = validation.min();
        int max = validation.max();
        boolean required = validation.required();
        
        for (Object arg : args) {
            if (arg == null) {
                if (required) {
                    throw new IllegalArgumentException("参数不能为空");
                }
                continue;
            }
            
            String value = arg.toString();
            
            // 校验正则表达式
            if (!pattern.isEmpty() && !Pattern.matches(pattern, value)) {
                throw new IllegalArgumentException("参数格式不正确");
            }
            
            // 校验长度范围
            if (value.length() < min || value.length() > max) {
                throw new IllegalArgumentException("参数长度必须在 " + min + " 到 " + max + " 之间");
            }
        }
    }
}
```

### 8.1 注解 + 工厂模式

public class ProductB implements Product {

## 9. 常见框架中的注解应用

### 9.1 Spring 注解

```java
@Controller
@RequestMapping("/user")
public class UserController {
    
    @Autowired
    private UserService userService;
    
    @GetMapping("/{id}")
    public User getUser(@PathVariable Long id) {
        return userService.getById(id);
    }
    
    @PostMapping
    public Result saveUser(@RequestBody @Valid User user) {
        userService.save(user);
        return Result.success();
    }
}
```

### 9.2 MyBatis 注解

```java
public interface UserMapper {
    
    @Select("SELECT * FROM user WHERE id = #{id}")
    User selectById(Long id);
    
    @Insert("INSERT INTO user(name, age) VALUES(#{name}, #{age})")
    @Options(useGeneratedKeys = true, keyProperty = "id")
    int insert(User user);
    
    @Update("UPDATE user SET name = #{name} WHERE id = #{id}")
    int update(User user);
    
    @Delete("DELETE FROM user WHERE id = #{id}")
    int delete(Long id);
}
```

## 10. 总结

本节介绍了自定义注解与反射处理的核心内容：

- **反射获取注解**：通过 Class、Method、Field 对象的 getAnnotation() 方法
- **自定义注解**：使用 @interface 定义，结合元注解指定保留策略和目标
- **注解处理器**：通过反射获取注解信息，实现相应的业务逻辑
- **框架应用**：Spring、MyBatis 等框架的注解应用示例

掌握这些知识后，你可以：
1. 自定义注解解决实际问题
2. 通过反射处理注解实现框架功能
3. 理解 Spring 等框架的注解实现原理

注解与反射的结合是 Java 框架的核心机制，深入理解这一机制对于学习主流 Java 框架至关重要。
