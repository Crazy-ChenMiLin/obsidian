# 注解与框架整合

## 1. 概述

现代 Java 框架大量使用注解来简化配置和提高开发效率。本节将介绍注解与常见框架的整合方式，包括 Spring、MyBatis、Hibernate 等。

## 2. Spring 核心注解

### 2.1 Bean 相关注解


```java
// @Component：通用组件
@Component
public class UserDao {
    public User findById(Long id) {
        return new User();
    }
}

// @Repository：数据访问层组件
@Repository
public class UserRepository {
    public User findById(Long id) {
        return new User();
    }
}

// @Service：业务逻辑层组件
@Service
public class UserService {
    public User getUser(Long id) {
        return new User();
    }
}

// @Controller：控制器层组件
@Controller
public class UserController {
    public User getUser(Long id) {
        return new User();
    }
}
```

### 2.2 依赖注入注解

```java
// @Autowired：按类型自动装配
@Service
public class UserService {
    @Autowired
    private UserRepository userRepository;
}

// @Qualifier：按名称指定 Bean
@Service
public class UserService {
    @Autowired
    @Qualifier("userRepository")
    private UserRepository userRepository;
}

// @Resource：按名称自动装配
@Service
public class UserService {
    @Resource(name = "userRepository")
    private UserRepository userRepository;
}

// @Value：注入普通值
@Service
public class UserService {
    @Value("${app.name}")
    private String appName;
}
```

### 2.3 配置类注解

```java
// @Configuration：配置类
@Configuration
```

## 3. Spring MVC 注解

### 3.1 请求处理注解

```java
@Controller
@RequestMapping("/api")
public class UserController {
    
    // @RequestMapping：映射请求
    @RequestMapping(value = "/user", method = RequestMethod.GET)
    public String getUser() {
        return "user";
    }
    
    // @GetMapping：GET 请求
    @GetMapping("/user/{id}")
    public User getUser(@PathVariable Long id) {
        return userService.getById(id);
    }
    
    // @PostMapping：POST 请求
    @PostMapping("/user")
    public Result saveUser(@RequestBody User user) {
        userService.save(user);
        return Result.success();
    }
    
    // @PutMapping：PUT 请求
    @PutMapping("/user/{id}")
    public Result updateUser(@PathVariable Long id, @RequestBody User user) {
        user.setId(id);
        userService.update(user);
        return Result.success();
    }
    
    // @DeleteMapping：DELETE 请求
    @DeleteMapping("/user/{id}")
    public Result deleteUser(@PathVariable Long id) {
        userService.delete(id);
        return Result.success();
    }
}
```

### 3.2 参数绑定注解

```java
@Controller
@RequestMapping("/api")
public class UserController {
    
    // @PathVariable：路径变量
    @GetMapping("/user/{id}")
    public User getUser(@PathVariable Long id) {
        return userService.getById(id);
    }
    
    // @RequestParam：请求参数
    @GetMapping("/user/search")
    public List<User> searchUsers(@RequestParam String name, 
                                   @RequestParam(required = false) Integer age) {
        return userService.search(name, age);
    }
    
    // @RequestBody：请求体
    @PostMapping("/user")
    public Result saveUser(@RequestBody User user) {
        userService.save(user);
        return Result.success();
    }
    
    // @RequestHeader：请求头
    @GetMapping("/user/detail")
    public User getUserDetail(@RequestHeader("Authorization") String token) {
        return userService.getUserDetail(token);
    }
    
    // @CookieValue：Cookie 值
    @GetMapping("/user/info")
    public User getUserInfo(@CookieValue("sessionId") String sessionId) {
        return userService.getUserInfo(sessionId);
    }
}
```

### 3.3 数据校验注解

```java
public class User {
    @NotNull(message = "用户名不能为空")
    @Size(min = 3, max = 20, message = "用户名长度必须在3-20之间")
    private String username;
    
    @NotBlank(message = "密码不能为空")
    @Size(min = 6, max = 20, message = "密码长度必须在6-20之间")
    private String password;
    
    @Email(message = "邮箱格式不正确")
    private String email;
    
    @Pattern(regexp = "^1[3-9]\\d{9}$", message = "手机号格式不正确")
    private String phone;
    
    @Min(value = 0, message = "年龄不能小于0")
    @Max(value = 150, message = "年龄不能大于150")
    private Integer age;
}

@Controller
public class UserController {
    @PostMapping("/user")
    public Result saveUser(@Valid @RequestBody User user, BindingResult bindingResult) {
        if (bindingResult.hasErrors()) {
            String message = bindingResult.getFieldError().getDefaultMessage();
            return Result.error(message);
        }
        userService.save(user);
        return Result.success();
    }
}
```

## 4. MyBatis 注解

### 4.1 基础映射注解

```java
public interface UserMapper {
    
    // @Select：查询
    @Select("SELECT * FROM user WHERE id = #{id}")
    User selectById(Long id);
    
    // @Insert：插入
    @Insert("INSERT INTO user(name, age, email) VALUES(#{name}, #{age}, #{email})")
    @Options(useGeneratedKeys = true, keyProperty = "id")
    int insert(User user);
    
    // @Update：更新
    @Update("UPDATE user SET name = #{name}, age = #{age}, email = #{email} WHERE id = #{id}")
    int update(User user);
    
    // @Delete：删除
    @Delete("DELETE FROM user WHERE id = #{id}")
    int delete(Long id);
}
```

### 4.2 动态 SQL 注解

```java
public interface UserMapper {
    
    // 使用 <script> 标签实现动态 SQL
    @Select("<script>" +
            "SELECT * FROM user " +
            "<where>" +
            "<if test='name != null'> AND name LIKE #{name}</if>" +
            "<if test='age != null'> AND age = #{age}</if>" +
            "<if test='email != null'> AND email = #{email}</if>" +
            "</where>" +
            "</script>")
    List<User> selectByCondition(User user);
    
    // @Results：结果映射
    @Results({
        @Result(property = "id", column = "id"),
        @Result(property = "name", column = "name"),
        @Result(property = "age", column = "age"),
        @Result(property = "email", column = "email"),
        @Result(property = "createTime", column = "create_time")
    })
    @Select("SELECT * FROM user WHERE id = #{id}")
    User selectById(Long id);
}
```

## 5. Lombok 注解

Lombok 是一个简化 Java 代码的注解库，通过注解自动生成 getter/setter/构造函数等代码。

### 5.1 数据注解

```java
// @Data：生成所有 getter/setter/toString/equals/hashCode
@Data
public class User {
    private Long id;
    private String name;
    private Integer age;
}

// @Getter：只生成 getter
@Getter
public class User {
    private Long id;
    private String name;
}

// @Setter：只生成 setter
@Setter
public class User {
    private Long id;
    private String name;
}

// @ToString：生成 toString
@ToString(exclude = {"password"})
public class User {
    private Long id;
    private String name;
    private String password;
}
```

### 5.2 构造方法注解

```java
// @NoArgsConstructor：生成无参构造
@NoArgsConstructor
public class User {
    private Long id;
    private String name;
}

// @AllArgsConstructor：生成全参构造
@AllArgsConstructor
public class User {
    private Long id;
    private String name;
}

// @RequiredArgsConstructor：生成必需参数构造
@RequiredArgsConstructor
public class User {
    private final Long id;
    private String name;
}
```

### 5.3 其他常用注解

```java

@Builder

    private Integer age;
```

## 6. 自定义业务注解

### 6.1 日志注解

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface LogAnnotation {
    String module() default "";
    String operation() default "";
}

// 使用
public class UserService {
    @LogAnnotation(module = "用户模块", operation = "添加用户")
    public void addUser(User user) {
        // 业务逻辑
    }
}

// 切面处理
@Aspect
@Component
public class LogAspect {
    
    @Around("@annotation(LogAnnotation)")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        MethodSignature signature = (MethodSignature) joinPoint.getSignature();
        LogAnnotation logAnnotation = signature.getMethod().getAnnotation(LogAnnotation.class);
        
        String module = logAnnotation.module();
        String operation = logAnnotation.operation();
        
        long startTime = System.currentTimeMillis();
        
        try {
            Object result = joinPoint.proceed();
            
            long endTime = System.currentTimeMillis();
            System.out.println(module + " - " + operation + " - 耗时: " + (endTime - startTime) + "ms");
            
            return result;
        } catch (Exception e) {
            System.out.println(module + " - " + operation + " - 异常: " + e.getMessage());
            throw e;
        }
    }
}
```

## 7. 注解的优缺点

### 7.1 优点

1. **简化配置**：减少 XML 配置文件
2. **提高开发效率**：代码更简洁
3. **增强可读性**：代码即配置，一目了然
4. **便于维护**：配置与代码在一起，易于管理
5. **框架集成**：与现代框架无缝集成

### 7.2 缺点

1. **增加复杂度**：注解本身需要学习成本
2. **反射性能**：运行时处理注解有性能开销
3. **耦合性**：注解与代码紧耦合
4. **难以复用**：注解只能用于特定目标
5. **调试困难**：注解的处理逻辑不易追踪

## 8. 总结

本节介绍了注解与常见框架的整合方式：

- **Spring 核心注解**：Bean、依赖注入、配置类等
- **Spring MVC 注解**：请求处理、参数绑定、数据校验
- **MyBatis 注解**：SQL 映射、动态 SQL
- **Lombok 注解**：简化代码、自动生成方法
- **自定义业务注解**：日志、权限等切面处理

通过深入理解这些注解的原理和应用，你可以：
1. 更好地使用现有框架
2. 自定义注解解决实际问题
3. 理解框架的内部实现机制

注解是现代 Java 开发的重要组成部分，掌握它对于提升开发效率和技术深度都有重要意义。
