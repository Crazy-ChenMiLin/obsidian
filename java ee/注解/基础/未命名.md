## 1. 注解是什么

- 给**类、属性、方法**加的**标记 / 标签**
- 本身不执行代码，只存信息，靠**反射**读取使用

## 2. 元注解（修饰注解的注解）

只用记两个最核心的：

1. **@Target**
    - 作用：规定注解能用在哪
    - 常用：
        
        - `ElementType.TYPE`：类、接口
        - `ElementType.FIELD`：成员变量（属性）
2. **@Retention**
    
    - 作用：规定注解保留到什么时候
    - 必须写：`RetentionPolicy.RUNTIME`
    - 原因：只有运行时保留，反射才能读到
    

## 3. 自定义注解语法

@interface

```
@Target(...)
@Retention(RetentionPolicy.RUNTIME)
public @interface 注解名 {
    // 参数格式：类型 参数名() default 默认值;
    String value();
    boolean nullable() default true;
}
```
