# 注解基础知识点

## 7. 小结

- 注解是代码中的特殊标记，提供元数据
- 使用 @interface 定义注解
- 常见预定义注解：@Override、@Deprecated、@SuppressWarnings、@FunctionalInterface
- 元注解：@Retention、@Target、@Documented、@Inherited
- 注解广泛应用于编译检查、框架配置、文档生成、运行时处理等场景

## 6. 注解基础注意事项

1. **注解不能包含业务逻辑**：注解只是标记，具体逻辑需要通过反射处理。
2. **注解属性必须有默认值**：否则使用时必须提供值。
3. **注解可以标记多种目标**：使用 @Target 指定。
4. **注解的保留策略很重要**：决定了注解在哪个阶段可用。
5. **注解是编译时处理**：大多数注解在编译时被处理，不会直接影响运行时性能。

掌握这些基础知识后，我们将在进阶课程中学习如何通过反射处理注解，以及自定义注解的高级用法




## 1. 什么是注解？

注解（Annotation）是 Java 5 引入的一种语法糖，它是代码中的特殊标记，用来为代码提供元数据。注解不会直接影响代码的执行，但可以通过反射机制在运行时获取注解信息，从而影响程序行为。

**简单理解**：注解就是给程序打标签，告诉程序这个类、方法、变量是什么、做什么用的。

## 2. 注解的组成

### 2.1 注解的定义

注解使用 `@interface` 关键字定义：

```java
public @interface MyAnnotation {
    // 注解的属性
}
```

### 2.2 注解的属性

注解可以包含属性，属性必须有默认值：

```java
public @interface MyAnnotation {
    String name() default "默认值";
    int age() default 0;
    boolean flag() default true;
}
```

### 2.3 注解的使用

```java
@MyAnnotation(name = "测试", age = 18)
public class MyClass {
    // 类上使用注解
}

@MyAnnotation(name = "方法")
public void myMethod() {
    // 方法上使用注解
}

@MyAnnotation(age = 25)
public String field;
```

## 3. 常见的预定义注解

Java 自带了一些常用的注解：

### 3.1 @Override

表示方法重写，如果父类没有该方法，编译器会报错：

```java
class Parent {
    public void show() {
        System.out.println("Parent");
    }
}

class Child extends Parent {
    @Override
    public void show() {
        System.out.println("Child");
    }
}
```

### 3.2 @Deprecated

表示已过时的元素，编译器会发出警告：

```java
@Deprecated
public void oldMethod() {
    System.out.println("这个方法已经过时了");
}
```

### 3.3 @SuppressWarnings

抑制编译器警告：

```java
@SuppressWarnings("unchecked")
public void oldStyleCode() {
    List list = new ArrayList();
    // 不会产生警告
}
```

### 3.4 @FunctionalInterface

表示函数式接口（只有一个抽象方法的接口）：

```java
@FunctionalInterface
public interface MyInterface {
    void doSomething();
    
    // default 方法不计入抽象方法
    default void doOtherThing() {
        System.out.println("默认实现");
    }
}
```

## 4. 元注解

元注解是用来注解其他注解的注解：

### 4.1 @Retention

表示注解的保留阶段：

```java
// SOURCE：只在源码中保留，编译时会被丢弃
@Retention(RetentionPolicy.SOURCE)
public @interface SourceAnnotation { }

// CLASS：保留到编译时，但运行时会被丢弃（默认）
@Retention(RetentionPolicy.CLASS)
public @interface ClassAnnotation { }

// RUNTIME：一直保留到运行时，可以通过反射获取
@Retention(RetentionPolicy.RUNTIME)
public @interface RuntimeAnnotation { }
```

### 4.2 @Target

表示注解可以应用的位置：

```java
// TYPE：类、接口、枚举
@Target(ElementType.TYPE)
public @interface TypeAnnotation { }

// METHOD：方法
@Target(ElementType.METHOD)
public @interface MethodAnnotation { }

// FIELD：字段
@Target(ElementType.FIELD)
public @interface FieldAnnotation { }

// CONSTRUCTOR：构造方法
@Target(ElementType.CONSTRUCTOR)
public @interface ConstructorAnnotation { }

// PARAMETER：方法参数
@Target(ElementType.PARAMETER)
public @interface ParameterAnnotation { }

// 多个位置
@Target({ElementType.TYPE, ElementType.METHOD, ElementType.FIELD})
public @interface MultiAnnotation { }
```

### 4.3 @Documented

表示注解会被包含在 JavaDoc 中：

```java
@Documented
@Retention(RetentionPolicy.RUNTIME)
public @interface DocumentedAnnotation { }
```

### 4.4 @Inherited

表示子类会继承父类的注解：

```java
@Inherited
@Retention(RetentionPolicy.RUNTIME)
public @interface InheritedAnnotation { }

@InheritedAnnotation
class Parent { }

class Child extends Parent { } // Child 也会拥有 @InheritedAnnotation
```

## 5. 注解的使用场景

### 5.1 编译检查

如 `@Override`、`@Deprecated`、`@FunctionalInterface` 等，用于编译器检查。

### 5.2 框架配置

Spring、Hibernate、MyBatis 等框架大量使用注解进行配置：

```java
// Spring 注解示例
@Controller
@RequestMapping("/user")
public class UserController {
    
    @Autowired
    private UserService userService;
    
    @GetMapping("/{id}")
    public User getUser(@PathVariable Long id) {
        return userService.getById(id);
    }
}
```

### 5.3 文档生成

通过注解配合工具生成文档。

### 5.4 运行时处理

通过反射获取注解信息，进行相应的处理。
