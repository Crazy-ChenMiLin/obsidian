# 注解选择题

## 选择题

1. 下列关于注解的说法，正确的是：  A
   A. 注解是 Java 5 才引入的特性 
   B. 注解会直接影响代码的执行逻辑 
   C. 注解只能用于类上  
   D. 注解不能包含属性  

2. 以下哪个是定义注解的关键字： A
   A. @interface
   B. @implementation
   C. @definition
   D. @annotation

3. @Override 注解的作用是： B
   A. 标记方法已过时
   B. 表示方法重写
   C. 抑制编译器警告
   D. 表示函数式接口

4. @Retention(RetentionPolicy.RUNTIME) 表示： C
   A. 注解只在源码中保留
   B. 注解在编译时被丢弃
   C. 注解一直保留到运行时，可以通过反射获取
   D. 注解在类加载时被丢弃

5. @Target(ElementType.METHOD) 表示注解可以应用在： C
   A. 类上
   B. 接口上
   C. 方法上
   D. 字段上

6. 以下哪个注解用于表示子类会继承父类的注解： D
   A. @Retention
   B. @Target
   C. @Documented
   D. @Inherited

7. 通过反射获取注解的方法是： A
   A. getAnnotation()
   B. getAnnotations()
   C. isAnnotationPresent()
   D. 以上都是
	==D==



8. 以下哪个不是 Java 的预定义注解： D
   A. @Override
   B. @Deprecated
   C. @SuppressWarnings
   D. @NotNull

9. @FunctionalInterface 注解的作用是：   ==B==
   A. 表示接口可以被子类继承
   B. 表示函数式接口，只能有一个抽象方法 
   C. 表示接口已经过时
   D. 表示接口可以多继承

10. 注解的属性可以有默认值，使用哪个关键字： A
    A. default
    B. value
    C. defaultValue
    D. initial

## 答案

1. A
2. A
3. B
4. C
5. C
6. D
7. D
8. D
9. B
10. A
