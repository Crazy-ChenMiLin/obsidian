Redis 是**单线程执行命令**的，规则只有一条：

✅ **单个命令**（`GETBIT`/`SETBIT`/`HGET`/`HSET`）：**原子执行，不可被打断**

❌ **多个命令组合**（GET+SET）：**执行完第一个命令后，一定可以插入其他命令，一定会被打断**

👉 也就是说：

`GETBIT → 中间插入其他命令 → SETBIT`

`HGET → 中间插入其他命令 → HSET`

**这两种情况，都会被打断！没有任何区别！**

只是bitmap保证了幂等性

# 三、让两个命令「绝对不被打断」的方案

如果你想让 `判断 + 更新` **完全不被插入任何命令**，百分百原子执行：

👉 用 **Lua 脚本**（Redis 单线程执行整个脚本，不可中断）

这才是 Redis 中**组合操作原子性**的唯一解法，不管是 Bitmap 还是 Hash 都适用。
