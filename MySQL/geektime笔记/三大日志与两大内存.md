# 一. 三大日志
## 1.1 binlog
### Binlog 三种记录格式

| 格式        | 记录核心            | 用例子说明                              | 优点              | 缺点         | 推荐度      |
| --------- | --------------- | ---------------------------------- | --------------- | ---------- | -------- |
| STATEMENT | 存「操作指令」（SQL 语句） | 存 `update T set c=c+1 where ID=2;` | 日志极小、性能高        | 数据易不一致（致命） | ❌ 不用     |
| ROW       | 存「数据变化」（行前后值）   | 存 `ID=2的c从0变1`                     | 数据 100% 一致、绝对可靠 | 日志大、开销高    | ✅ 首选（默认） |
| MIXED     | 自动切换两种格式        | 普通 SQL 存语句，不确定 SQL 存行变化            | 兼顾空间和准确性        | 极端场景仍可     |          |
