# 一、数组最常用的 6 个基础操作（小白必背）

## 1. 定义数组

```
int[] arr = {1, 2, 3, 4, 5};
```

- 就是给数组起名字，直接放数字。

## 2. 取数组里的元素


```
int x = arr[2]; // 取第3个元素（索引2）
```

- 索引从 0 开始。

## 3. 修改数组里的元素


```
arr[1] = 10; // 把第2个元素改成10
```

## 4. 遍历数组（挨个看）


```
for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
```

- `arr.length` 是数组长度。

## 5. 数组赋值（复制）


```
int[] newArr = new int[arr.length];
for (int i = 0; i < arr.length; i++) {
    newArr[i] = arr[i];
}
```

## 6. 数组求和


```
int sum = 0;
for (int i = 0; i < arr.length; i++) {
    sum = sum + arr[i];
}
```

# 二、小白专属练习题（全部是数组操作，不涉及算法）

我给你 6 道题，你照着写就能完全掌握。

## 题 1：定义数组 `{2, 5, 7, 9}`，打印所有元素

```
int[] arr = {2, 5, 7, 9};
for (int i = 0; i < arr.length; i++) {
    System.out.print(arr[i] + " ");
}
```

## 题 2：把数组第 0 个元素改成 100

```
arr[0] = 100;
```

## 题 3：把数组所有元素都加 1

```
for (int i = 0; i < arr.length; i++) {
    arr[i] = arr[i] + 1;
}
```

## 题 4：求数组所有元素的和

```
int sum = 0;
for (int i = 0; i < arr.length; i++) {
    sum += arr[i];
}
System.out.println(sum);
```

## 题 5：把数组复制到新数组

```
int[] newArr = new int[arr.length];
for (int i = 0; i < arr.length; i++) {
    newArr[i] = arr[i];
}
```

## 题 6：把数组里的 0 移到最后（你已经会的）

```
int index = 0;
for (int i = 0; i < arr.length; i++) {
    if (arr[i] != 0) {
        arr[index] = arr[i];
        index++;
    }
}
for (int i = index; i < arr.length; i++) {
    arr[i] = 0;
}
```
