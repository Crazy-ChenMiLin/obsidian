# Canal 配置与启动

## 启动前的准备工作

### 1. 检查配置文件

确保以下配置文件已正确设置：

- **全局配置**：`conf/canal.properties`
- **实例配置**：`conf/example/instance.properties`

### 2. 验证 MySQL 连接

确保 Canal 可以连接到 MySQL：
- MySQL 服务已启动
- 网络连接正常
- Canal 用户名和密码正确
- 权限设置正确

### 3. 检查端口占用

确保 Canal 默认端口 11111 未被占用：

**Windows 系统**：
```bash
netstat -ano | findstr 11111
```

**Linux 系统**：
```bash
netstat -tlnp | grep 11111
```

## 启动 Canal

### Windows 系统

1. **打开命令提示符**（以管理员身份运行）
2. **进入 Canal 目录**：
   ```bash
   cd D:\canal\canal.deployer-1.1.8\bin
   ```
3. **启动 Canal**：
   ```bash
   .\startup.bat
   ```

### Linux 系统

1. **进入 Canal 目录**：
   ```bash
   cd /opt/canal/bin
   ```
2. **启动 Canal**：
   ```bash
   sh startup.sh
   ```

## 停止 Canal

### Windows 系统

1. **进入 Canal 目录**：
   ```bash
   cd D:\canal\canal.deployer-1.1.8\bin
   ```
2. **停止 Canal**：
   ```bash
   .\stop.bat
   ```

### Linux 系统

1. **进入 Canal 目录**：
   ```bash
   cd /opt/canal/bin
   ```
2. **停止 Canal**：
   ```bash
   sh stop.sh
   ```

## 验证 Canal 状态

### 1. 检查日志

**Windows 系统**：
- 日志文件位于 `D:\canal\canal.deployer-1.1.8\logs`
- 查看 `canal.log` 和 `example/example.log`

**Linux 系统**：
- 日志文件位于 `/opt/canal/logs`
- 查看 `canal.log` 和 `example/example.log`

### 2. 检查进程

**Windows 系统**：
```bash
tasklist | findstr java
```

**Linux 系统**：
```bash
ps aux | grep canal
```

### 3. 测试连接

使用 telnet 测试 Canal 服务是否正常：

```bash
telnet localhost 11111
```

如果连接成功，说明 Canal 服务已正常启动。

## 配置文件详解

### 全局配置文件（canal.properties）

关键配置项：

| 配置项                            | 说明           | 默认值             |
| --------------------------------- | -------------- | ------------------ |
| canal.port                        | Canal 服务端口 | 11111              |
| canal.ip                          | 绑定地址       | 空（默认所有地址） |
| canal.destinations                | 实例名称       | example            |
| canal.instance.memory.buffer.size | 内存缓冲区大小 | 16384              |
| canal.instance.parser.parallel    | 是否并行解析   | true               |

### 实例配置文件（instance.properties）

关键配置项：

| 配置项                            | 说明           | 默认值           |
| --------------------------------- | -------------- | ---------------- |
| canal.instance.master.address     | MySQL 主库地址 | 127.0.0.1:3306   |
| canal.instance.dbUsername         | MySQL 用户名   | canal            |
| canal.instance.dbPassword         | MySQL 密码     | canal            |
| canal.instance.filter.regex       | 监控表规则     | .*\..*（所有表） |
| canal.instance.filter.black.regex | 排除表规则     | 空               |

## 常见启动问题及解决

### 1. 端口被占用

**症状**：启动失败，日志显示端口 11111 已被占用

**解决方法**：
- 查找并关闭占用端口的进程
- 或修改 `canal.properties` 中的 `canal.port` 配置

### 2. MySQL 连接失败

**症状**：启动失败，日志显示无法连接到 MySQL

**解决方法**：
- 检查 MySQL 服务是否运行
- 检查 `instance.properties` 中的连接信息是否正确
- 检查网络连接是否正常
- 验证 Canal 用户权限是否正确

### 3. binlog 配置错误

**症状**：启动失败，日志显示 binlog 相关错误

**解决方法**：
- 确认 MySQL 已开启 binlog
- 确认 binlog 格式为 ROW 模式
- 确认 server-id 已设置且唯一

### 4. 内存不足

**症状**：启动失败，日志显示内存不足

**解决方法**：
- 增加系统内存
- 或修改 JVM 内存配置（在 `bin/startup.sh` 或 `bin/startup.bat` 中）

## 启动脚本说明

### Windows 启动脚本（startup.bat）

主要功能：
- 设置 JVM 内存参数
- 启动 Canal 服务
- 后台运行

### Linux 启动脚本（startup.sh）

主要功能：
- 设置 JVM 内存参数
- 启动 Canal 服务
- 后台运行
- 记录进程 ID

## 小结

启动 Canal 的步骤：

1. **准备工作**：检查配置文件、验证 MySQL 连接、检查端口
2. **启动服务**：执行启动脚本
3. **验证状态**：检查日志、进程和连接
4. **排查问题**：根据错误信息解决常见问题

正确的启动和配置是使用 Canal 的基础，确保这些步骤都正确完成后，Canal 就能正常工作了。
