# Canal 安装与环境配置

## 环境要求

### 1. 硬件要求
- **CPU**：至少 2 核
- **内存**：至少 2GB
- **磁盘**：至少 5GB 可用空间

### 2. 软件要求
- **Java**：JDK 1.8 或更高版本
- **MySQL**：5.6 或更高版本（推荐 5.7+）
- **操作系统**：Windows、Linux、MacOS 均可

## MySQL 配置

Canal 依赖 MySQL 的 binlog 功能，需要确保 MySQL 开启了 binlog 且格式正确。

### 1. 检查 MySQL 版本
```bash
# Windows 命令提示符或 PowerShell
mysql --version

# Linux/Mac
mysql -V
```

### 2. 开启 binlog

编辑 MySQL 配置文件（my.cnf 或 my.ini）：

**Windows 系统**：
- 通常位于 `C:\ProgramData\MySQL\MySQL Server 5.7\my.ini`
- 或 `C:\Program Files\MySQL\MySQL Server 5.7\my.ini`

**Linux 系统**：
- 通常位于 `/etc/my.cnf` 或 `/etc/mysql/my.cnf`

### 3. 添加 binlog 配置

在配置文件的 `[mysqld]` 部分添加以下内容：

```ini
# 开启 binlog
log-bin=mysql-bin

# binlog 格式，必须为 ROW 模式
binlog-format=ROW

# 服务器 ID，必须唯一
server-id=1

# 保留 binlog 的天数
expire_logs_days=7

# 每次事务提交时都刷新 binlog 到磁盘（可选，提高可靠性）
sync_binlog=1
```

### 4. 重启 MySQL 服务

**Windows 系统**：
- 通过服务管理器重启 MySQL 服务
- 或使用命令：`net stop mysql && net start mysql`

**Linux 系统**：
- `systemctl restart mysql` 或 `service mysql restart`

### 5. 验证 binlog 配置

登录 MySQL 并执行：

```sql
SHOW VARIABLES LIKE 'log_bin';
SHOW VARIABLES LIKE 'binlog_format';
SHOW VARIABLES LIKE 'server_id';
```

确保返回结果中：
- `log_bin` 的值为 `ON`
- `binlog_format` 的值为 `ROW`
- `server_id` 有值且唯一

### 6. 创建 Canal 专用用户

为 Canal 创建一个具有复制权限的用户：

```sql
-- 创建用户
CREATE USER 'canal'@'%' IDENTIFIED BY 'canal';

-- 授权
GRANT SELECT, REPLICATION SLAVE, REPLICATION CLIENT ON *.* TO 'canal'@'%';

-- 刷新权限
FLUSH PRIVILEGES;
```

## Canal 下载与安装

### 1. 下载 Canal

访问 GitHub 下载页面：[https://github.com/alibaba/canal/releases](https://github.com/alibaba/canal/releases)

选择适合的版本，推荐下载最新的稳定版，如 `canal.deployer-1.1.8.tar.gz`（Windows 用户也可以下载这个版本）。

### 2. 安装 Canal

**Windows 系统**：
1. 解压下载的 `canal.deployer-1.1.8.tar.gz` 文件
2. 建议解压到 `D:\canal\canal.deployer-1.1.8` 目录

**Linux 系统**：
1. 解压文件：`tar -zxvf canal.deployer-1.1.8.tar.gz -C /opt/canal`
2. 进入目录：`cd /opt/canal`

## Canal 目录结构

Canal 的目录结构如下：

```
canal.deployer-1.1.8/
├── bin/             # 可执行脚本
│   ├── startup.sh   # Linux 启动脚本
│   └── startup.bat  # Windows 启动脚本
├── conf/            # 配置文件目录
│   ├── canal.properties        # 全局配置文件
│   └── example/                # 实例配置目录
│       └── instance.properties # 实例配置文件
├── lib/             # 依赖库
└── logs/            # 日志目录
```

## 配置文件详解

### 1. 全局配置文件（canal.properties）

主要配置项：

```properties
# Canal 服务端口
canal.port = 11111

# Canal 服务绑定的地址
canal.ip = 

#  canal 实例配置目录
canal.destinations = example

# ZooKeeper 地址（用于集群部署）
canal.zkServers = 

# 内存存储模式
canal.instance.memory.buffer.size = 16384

# 并发处理数量
canal.instance.parser.parallel = true
```

### 2. 实例配置文件（instance.properties）

主要配置项：

```properties
# MySQL 连接信息
canal.instance.master.address = 127.0.0.1:3306

# MySQL 用户名和密码
canal.instance.dbUsername = canal
canal.instance.dbPassword = canal

# 连接池配置
canal.instance.connectionCharset = UTF-8

# binlog 起始位置
canal.instance.master.journal.name =
canal.instance.master.position =
canal.instance.master.timestamp =

# 过滤规则
canal.instance.filter.regex = .*\..*
canal.instance.filter.black.regex = 
```

### 3. 配置说明

- **master.address**：MySQL 主库地址和端口
- **dbUsername/dbPassword**：之前创建的 Canal 专用用户
- **filter.regex**：需要监控的表，默认监控所有表
- **filter.black.regex**：需要排除的表

## 配置示例

### 监控指定数据库和表

如果只需要监控特定的数据库和表，可以修改 `filter.regex`：

```properties
# 监控 test 数据库的所有表
canal.instance.filter.regex = test\..*

# 监控 test 数据库的 user 和 order 表
canal.instance.filter.regex = test\.user|test\.order
```

## 安装验证

### 1. 检查 Java 环境

```bash
# 检查 Java 版本
java -version

# 确保输出 Java 1.8 或更高版本
```

### 2. 检查 Canal 目录结构

确保 Canal 解压后的目录结构完整，特别是 `bin`、`conf` 目录。

### 3. 验证 MySQL 配置

再次确认 MySQL 的 binlog 配置是否正确：

```sql
SHOW VARIABLES LIKE 'log_bin';
SHOW VARIABLES LIKE 'binlog_format';
```

### 4. 验证 Canal 用户权限

```sql
SHOW GRANTS FOR 'canal'@'%';
```

## 小结

安装和配置 Canal 的关键步骤：

1. **配置 MySQL**：开启 binlog，设置正确的格式和 server-id
2. **创建用户**：为 Canal 创建具有复制权限的用户
3. **下载安装**：下载并解压 Canal 到合适的目录
4. **配置 Canal**：修改全局配置和实例配置
5. **验证环境**：确保所有配置都正确无误

在完成这些步骤后，就可以启动 Canal 服务了。
