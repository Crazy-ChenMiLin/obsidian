# Canal 实战示例

## 1. Java 客户端示例

### 环境准备

- **Java 开发环境**：JDK 1.8 或更高版本
- **Maven**：用于依赖管理
- **Canal 服务**：已启动并运行

### 依赖配置

在 Maven 项目的 `pom.xml` 文件中添加 Canal 客户端依赖：

```xml
<dependencies>
    <!-- Canal 客户端依赖 -->
    <dependency>
        <groupId>com.alibaba.otter</groupId>
        <artifactId>canal.client</artifactId>
        <version>1.1.8</version>
    </dependency>
    <!-- JSON 处理依赖 -->
    <dependency>
        <groupId>com.alibaba</groupId>
        <artifactId>fastjson</artifactId>
        <version>1.2.83</version>
    </dependency>
</dependencies>
```

### 示例代码

```java
import com.alibaba.otter.canal.client.CanalConnector;
import com.alibaba.otter.canal.client.CanalConnectors;
import com.alibaba.otter.canal.protocol.CanalEntry;
import com.alibaba.otter.canal.protocol.Message;
import com.alibaba.fastjson.JSONObject;

import java.net.InetSocketAddress;
import java.util.List;

public class CanalClientExample {
    public static void main(String[] args) {
        // 创建 Canal 连接器
        CanalConnector connector = CanalConnectors.newSingleConnector(
                new InetSocketAddress("127.0.0.1", 11111),
                "example",
                "", ""
        );

        try {
            // 连接 Canal 服务
            connector.connect();
            // 订阅所有表
            connector.subscribe("\".*\\..*\"");
            // 回滚到上次消费的位置
            connector.rollback();

            while (true) {
                // 获取消息，每次最多获取 1000 条
                Message message = connector.getWithoutAck(1000);
                long batchId = message.getId();
                int size = message.getEntries().size();

                if (batchId == -1 || size == 0) {
                    // 没有消息，休眠 1 秒
                    try {
                        Thread.sleep(1000);
                    } catch (InterruptedException e) {
                        e.printStackTrace();
                    }
                } else {
                    // 处理消息
                    processEntries(message.getEntries());
                    // 确认消费
                    connector.ack(batchId);
                }
            }
        } finally {
            // 关闭连接
            connector.disconnect();
        }
    }

    private static void processEntries(List<CanalEntry.Entry> entries) {
        for (CanalEntry.Entry entry : entries) {
            // 只处理行数据变更
            if (entry.getEntryType() == CanalEntry.EntryType.ROWDATA) {
                try {
                    CanalEntry.RowChange rowChange = CanalEntry.RowChange.parseFrom(entry.getStoreValue());
                    String tableName = entry.getHeader().getTableName();
                    String databaseName = entry.getHeader().getSchemaName();

                    for (CanalEntry.RowData rowData : rowChange.getRowDatasList()) {
                        if (rowChange.getEventType() == CanalEntry.EventType.INSERT) {
                            // 处理插入操作
                            System.out.println("[INSERT] " + databaseName + "." + tableName);
                            printColumns(rowData.getAfterColumnsList());
                        } else if (rowChange.getEventType() == CanalEntry.EventType.UPDATE) {
                            // 处理更新操作
                            System.out.println("[UPDATE] " + databaseName + "." + tableName);
                            System.out.println("Before:");
                            printColumns(rowData.getBeforeColumnsList());
                            System.out.println("After:");
                            printColumns(rowData.getAfterColumnsList());
                        } else if (rowChange.getEventType() == CanalEntry.EventType.DELETE) {
                            // 处理删除操作
                            System.out.println("[DELETE] " + databaseName + "." + tableName);
                            printColumns(rowData.getBeforeColumnsList());
                        }
                    }
                } catch (Exception e) {
                    e.printStackTrace();
                }
            }
        }
    }

    private static void printColumns(List<CanalEntry.Column> columns) {
        JSONObject json = new JSONObject();
        for (CanalEntry.Column column : columns) {
            json.put(column.getName(), column.getValue());
        }
        System.out.println(json.toJSONString());
    }
}
```

### 运行说明

1. 确保 Canal 服务已启动
2. 运行上述 Java 代码
3. 在 MySQL 中对监控的表进行增删改操作
4. 观察控制台输出，应该能看到数据变更的详细信息

## 2. Kafka 集成示例

### 环境准备

- **Kafka**：已安装并运行
- **Canal 服务**：已安装

### 配置修改

修改 `conf/canal.properties` 文件：

```properties
# 启用 Kafka 模式
canal.serverMode = kafka

# Kafka 集群地址
canal.mq.servers = 127.0.0.1:9092

# Kafka 主题名称
canal.mq.topic = canal-topic

# 分区数
canal.mq.partitionsNum = 1

# 分区规则
canal.mq.partitionHash = test\.user:id,test\.order:order_id
```

### 启动 Kafka

```bash
# 启动 Zookeeper
bin/zookeeper-server-start.sh config/zookeeper.properties

# 启动 Kafka
bin/kafka-server-start.sh config/server.properties

# 创建主题
bin/kafka-topics.sh --create --bootstrap-server localhost:9092 --replication-factor 1 --partitions 1 --topic canal-topic
```

### 启动 Canal

```bash
# 启动 Canal
bin/startup.sh
```

### 消费 Kafka 消息

```java
import org.apache.kafka.clients.consumer.ConsumerConfig;
import org.apache.kafka.clients.consumer.ConsumerRecord;
import org.apache.kafka.clients.consumer.ConsumerRecords;
import org.apache.kafka.clients.consumer.KafkaConsumer;

import java.time.Duration;
import java.util.Collections;
import java.util.Properties;

public class KafkaConsumerExample {
    public static void main(String[] args) {
        Properties props = new Properties();
        props.put(ConsumerConfig.BOOTSTRAP_SERVERS_CONFIG, "127.0.0.1:9092");
        props.put(ConsumerConfig.GROUP_ID_CONFIG, "canal-consumer-group");
        props.put(ConsumerConfig.KEY_DESERIALIZER_CLASS_CONFIG, "org.apache.kafka.common.serialization.StringDeserializer");
        props.put(ConsumerConfig.VALUE_DESERIALIZER_CLASS_CONFIG, "org.apache.kafka.common.serialization.StringDeserializer");
        props.put(ConsumerConfig.AUTO_OFFSET_RESET_CONFIG, "earliest");

        KafkaConsumer<String, String> consumer = new KafkaConsumer<>(props);
        consumer.subscribe(Collections.singletonList("canal-topic"));

        try {
            while (true) {
                ConsumerRecords<String, String> records = consumer.poll(Duration.ofMillis(100));
                for (ConsumerRecord<String, String> record : records) {
                    System.out.println("Received message: " + record.value());
                }
            }
        } finally {
            consumer.close();
        }
    }
}
```

## 3. Elasticsearch 集成示例

### 环境准备

- **Elasticsearch**：已安装并运行
- **Canal 服务**：已安装
- **Canal Adapter**：用于将 Canal 数据同步到 Elasticsearch

### 安装 Canal Adapter

1. 下载 Canal Adapter：[https://github.com/alibaba/canal/releases](https://github.com/alibaba/canal/releases)
2. 解压到 `D:\canal\canal.adapter-1.1.8` 目录

### 配置修改

修改 `conf/application.yml` 文件：

```yaml
server:
  port: 8081
spring:
  jackson:
    date-format: yyyy-MM-dd HH:mm:ss
    time-zone: GMT+8
    default-property-inclusion: non_null

canal.conf:
  mode: tcp
  canalServerHost: 127.0.0.1:11111
  batchSize: 500
  syncBatchSize: 1000
  retries: 0
  timeout:
  accessKey:
  secretKey:
  srcDataSources:
    defaultDS:
      url: jdbc:mysql://127.0.0.1:3306/test?useUnicode=true
      username: canal
      password: canal
  canalAdapters:
  - instance: example
    groups:
    - groupId: g1
      outerAdapters:
      - name: es
        hosts: 127.0.0.1:9200
        properties:
          mode: rest
          cluster.name: docker-cluster
```

### 配置表映射

在 `conf/es` 目录下创建 `test_user.yml` 文件：

```yaml
dataSourceKey: defaultDS
destination: example
groupId: g1
esMapping:
  _index: test_user
  _type: _doc
  _id: id
  upsert: true
  sql: "SELECT id, name, age, create_time FROM user"
  etlCondition: "where id > {0}"
  commitBatch: 3000
```

### 启动 Canal Adapter

```bash
# 启动 Canal Adapter
bin/startup.bat
```

### 验证同步

1. 在 MySQL 中插入数据：
   ```sql
   INSERT INTO user (id, name, age, create_time) VALUES (1, '张三', 20, NOW());
   ```

2. 查看 Elasticsearch 中的数据：
   ```bash
   curl -X GET "localhost:9200/test_user/_search?pretty"
   ```

## 4. Redis 集成示例

### 环境准备

- **Redis**：已安装并运行
- **Canal 服务**：已安装
- **Canal Adapter**：已安装

### 配置修改

在 `conf/application.yml` 文件中添加 Redis 适配器配置：

```yaml
canalAdapters:
- instance: example
  groups:
  - groupId: g1
    outerAdapters:
    - name: redis
      hosts: 127.0.0.1:6379
      properties:
        mode: string
        key: test:%s
        value: {"id":"%s","name":"%s","age":%s}
```

### 配置表映射

在 `conf/redis` 目录下创建 `test_user.yml` 文件：

```yaml
dataSourceKey: defaultDS
destination: example
groupId: g1
redisMapping:
  database: 0
  table: user
  pk: id
  columns:
    id: id
    name: name
    age: age
  TTL: 60
```

### 启动 Canal Adapter

```bash
# 启动 Canal Adapter
bin/startup.bat
```

### 验证同步

1. 在 MySQL 中插入数据：
   ```sql
   INSERT INTO user (id, name, age) VALUES (2, '李四', 25);
   ```

2. 查看 Redis 中的数据：
   ```bash
   redis-cli get test:2
   ```

## 5. 监控和管理示例

### 1. 使用 Canal Admin

**Canal Admin** 是 Canal 官方提供的管理工具，用于管理 Canal 实例。

#### 安装 Canal Admin

1. 下载 Canal Admin：[https://github.com/alibaba/canal/releases](https://github.com/alibaba/canal/releases)
2. 解压到 `D:\canal\canal.admin-1.1.8` 目录
3. 初始化数据库（使用 `conf/canal_manager.sql`）
4. 修改 `conf/application.yml` 配置数据库连接

#### 启动 Canal Admin

```bash
# 启动 Canal Admin
bin/startup.bat
```

#### 访问管理界面

打开浏览器，访问 `http://localhost:8089`，使用默认账号密码（admin/admin）登录。

### 2. 集成 Prometheus 监控

#### 配置 Canal 暴露指标

修改 `conf/canal.properties` 文件：

```properties
# 启用 Prometheus 监控
canal.metrics.prometheus.enabled = true
canal.metrics.prometheus.port = 9101
```

#### 配置 Prometheus

在 `prometheus.yml` 文件中添加 Canal 监控目标：

```yaml
scrape_configs:
  - job_name: 'canal'
    static_configs:
      - targets: ['localhost:9101']
```

#### 启动 Prometheus 和 Grafana

1. 启动 Prometheus：`./prometheus --config.file=prometheus.yml`
2. 启动 Grafana：`./grafana-server`
3. 在 Grafana 中添加 Prometheus 数据源
4. 导入 Canal 监控面板

## 6. 最佳实践

### 1. 合理设置过滤规则

```properties
# 只同步必要的表
canal.instance.filter.regex = test\.user|test\.order

# 排除不需要的表
canal.instance.filter.black.regex = test\.log|test\.temp
```

### 2. 优化性能

- **调整批处理大小**：
  ```properties
  canal.instance.memory.batch.size = 16384
  ```

- **启用并行解析**：
  ```properties
  canal.instance.parser.parallel = true
  canal.instance.parser.parallelThreadSize = 4
  ```

- **合理设置缓冲区**：
  ```properties
  canal.instance.memory.buffer.size = 32768
  ```

### 3. 高可用配置

- **使用 ZooKeeper 管理**：
  ```properties
  canal.zkServers = 127.0.0.1:2181
  ```

- **部署多个 Canal 实例**，使用负载均衡

### 4. 数据一致性保证

- **使用消息队列**：如 Kafka，确保数据不丢失
- **实现幂等性处理**：确保重复消费不会导致数据错误
- **定期校验**：定期检查源数据和目标数据的一致性

## 小结

通过本文的实战示例，小白用户可以学习如何：

1. 使用 Java 客户端直接消费 Canal 数据
2. 与 Kafka 集成，实现高可靠的数据传输
3. 与 Elasticsearch 集成，实现数据实时索引
4. 与 Redis 集成，实现数据缓存更新
5. 使用 Canal Admin 进行管理
6. 集成 Prometheus 进行监控

这些示例覆盖了 Canal 的主要应用场景，帮助小白用户快速上手并在实际项目中应用 Canal。
