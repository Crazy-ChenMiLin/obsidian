| 特性         | Java 安全管理器（SecurityManager） | Spring Security Test           |
| ---------- | --------------------------- | ------------------------------ |
| **所属**     | JDK 原生，和 Spring 无关          | Spring 框架的测试模块                 |
| **作用范围**   | 整个 JVM 层面的权限控制              | 仅 Spring 应用的安全测试               |
| **控制内容**   | 文件读写、网络访问、线程启动等底层权限         | 用户登录、角色权限、接口访问等业务权限            |
| **是否需要依赖** | 不需要，JDK 自带                  | 需要引入 `spring-security-test` 依赖 |
| **现在还常用吗** | 很少用了（JDK 9+ 标记为过时）          | 非常常用（Spring 项目必用）              |
