| 对比维度  | su（切换用户）                              | sudo（临时提权）                   |
| ----- | ------------------------------------- | ---------------------------- |
| 本质    | 完全切换到另一个用户的身份                         | 还是用自己的账号，只是临时拿到管理员权限         |
| 密码要求  | 必须输入**目标用户的密码**（比如切 root 就要输 root 密码） | 输入**自己的密码**（或者像你配置的免密，不用输密码） |
| 适用场景  | 需要长时间用管理员身份操作很多事                      | 只是偶尔干一件需要管理员权限的事             |
| 你的场景里 | 因为不知道 root 密码，用不了                     | 配置了免密后，**这是你以后的首选**，方便安全     |
